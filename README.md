# Porsche Sales Analytics Dashboard

Dashboard executivo de vendas desenvolvido como projeto da Aceleração DIO Santander, com o objetivo de aplicar conceitos de análise de dados, visualização de informações e uso de Inteligência Artificial no desenvolvimento de uma solução em formato MVP.

## 🎯 Objetivo do Projeto

O projeto tem como objetivo transformar uma base de dados de vendas de veículos Porsche em um dashboard executivo interativo, permitindo visualizar indicadores relevantes e analisar o comportamento das vendas por diferentes dimensões.

O desenvolvimento foi realizado com apoio de Inteligência Artificial Generativa (ChatGPT), utilizada como ferramenta de suporte na estruturação da solução, desenvolvimento do código, análise dos dados e resolução de problemas durante a implementação.

## 📊 Principais Indicadores

O dashboard apresenta os seguintes KPIs:

- Total de vendas
- Receita total
- Ticket médio
- Modelo mais vendido

Além dos indicadores, são disponibilizadas análises por:

- Modelo Porsche
- Ano do modelo
- Cidade
- Forma de pagamento
- Receita por cidade

O dashboard também apresenta uma área de Executive Insights, que gera automaticamente informações relevantes a partir dos dados e dos filtros selecionados.

## 🔎 Filtros Interativos

O usuário pode analisar os dados utilizando filtros de:

- Modelo Porsche
- Model Year
- Cidade
- Forma de pagamento

Ao selecionar um filtro, os KPIs, gráficos e insights são recalculados automaticamente.

## 🛠️ Tecnologias Utilizadas

- HTML5 — estrutura da aplicação
- CSS3 — layout e identidade visual
- JavaScript — lógica, cálculos, filtros e interatividade
- Chart.js — criação dos gráficos
- JSON — armazenamento da base de dados utilizada pelo dashboard
- GitHub — versionamento e publicação do projeto
- GitHub Pages — disponibilização do dashboard na web
- ChatGPT — apoio ao desenvolvimento e construção do MVP
